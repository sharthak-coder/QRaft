# Screenshot Guide for QRaft

To capture polished screenshots for your GitHub repository and GDG SRM submission:

1. Run the application locally (`npm run dev`) or open your deployed live URL.
2. Open Chrome Developer Tools and set viewport or device simulation as desired.
3. Save the screenshots into this directory (`docs/screenshots/`) with the following names:

- `01-welcome.png`: Full-screen Welcome page hero with the animated Madhubani Rangoli QR code assembling radially outward on warm wasli paper.
- `02-generator.png`: 2D QR Generator showing the *Peacock Garden* or *Saffron Sun* preset with custom connected modules and circular finder rings.
- `03-reliability.png`: Close-up of the Scan-Reliability Engine banner with WCAG contrast score and automated *jsQR* scan verification badge.
- `04-3d-studio.png`: 3D WebGL Studio showcasing an angled 3D QR matrix with orbit view, depth extrusion, and Madhubani theme selector.
- `05-templates.png`: My Templates tab showing the card grid with mini QR previews and corner floral motifs.
- `06-community.png`: Community tab displaying authentic sample templates with remix buttons and author attribution.
- `07-terms.png`: Terms & Conditions page with the sticky table of contents and MIT licensing information.
- `08-mobile.png`: Mobile viewport (375px width) showing single-column layout, touch-friendly controls, and the sliding tab bar.
