# Screenshot Guide for QRaft

To capture polished screenshots for your GitHub repository and GDG SRM submission:

1. Run the application locally (`npm run dev`) or open your deployed Vercel URL.
2. Open Chrome Developer Tools and set viewport or device simulation as desired.
3. Save the screenshots into this directory (`docs/screenshots/`) with the following names:

- `01-welcome.png`: Full-screen Welcome page hero with the live typing synthesizer.
- `02-generator.png`: 2D QR Generator with input form on the left and live preview on the right.
- `03-reliability.png`: Close-up of the Scan-Reliability Engine banner with contrast score and jsQR check.
- `04-3d-studio.png`: 3D WebGL Studio showcasing an angled 3D QR matrix with orbit view and theme selector.
- `05-templates.png`: My Templates tab showing the card grid with mini QR previews.
- `06-community.png`: Community feed showing likes, remix buttons, and comment thread.
- `07-terms.png`: Terms & Conditions page with the sticky table of contents.
- `08-mobile.png`: Mobile viewport (360px width) showing single-column layout and sliding tab bar.
